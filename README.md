# Jemma’s Journals

The home page that links Jemma’s other sites: Sim World, Library and Pokédex.

- `concepts/` – the home page designs being tried (open `concepts/index.html`; the switch bottom right changes version).
- `for-jemma/concepts/` – screenshots of each round of designs.

Fonts: Instrument Serif and Manrope (SIL Open Font Licence). Icons: Lucide (ISC). World maps by 20th Century Plumbob; Pokémon pictures from the games; book covers from their publishers.
